Intro

Welcome to the Trivy Operator Dashboard, a comprehensive security management tool for Kubernetes environments.

Built on top of the powerful Trivy Operator from Aqua Security, this dashboard provides insights into your cluster's security posture. It offers detailed insights on vulnerability scans, policy validation scans, and other ones. With an intuitive and user-friendly interface, you can easily monitor, detect, and respond to security threats, ensuring your Kubernetes environment remains robust and secure.

All features consist of dashboards (for a quick overview), browsing and inspecting findings (with table filters, sorts), and exporting data.

More info on GitHub page.
